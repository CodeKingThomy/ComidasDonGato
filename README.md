# Comidas Don Gato
1. Instalar Node.js 18+ (nodejs.org)
2. `npm install`
3. `npm start`  → tienda: http://localhost:3000  |  admin: http://localhost:3000/admin.html
Variables opcionales: ADMIN_PASSWORD (default: dongato123), MP_ACCESS_TOKEN (Mercado Pago), BASE_URL (tu dominio https), PORT
Ej: ADMIN_PASSWORD=miclave MP_ACCESS_TOKEN=APP_USR-xxx npm start
